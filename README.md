# #fitcheck

A colourful, phone-friendly movement planner.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `fitcheck`.
2. Unzip this download and upload all four files (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) to the repository's main/root folder.
3. Commit the upload.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait a minute or two. GitHub will show your site address, usually `https://YOUR-USERNAME.github.io/fitcheck/`.

## Add it to your phone
- iPhone: Open the published link in Safari → Share → **Add to Home Screen** → Add.
- Android: Open the link in Chrome → menu (⋮) → **Install app** or **Add to Home screen**.

## Notes
- Entries are saved in this browser on this device only; they do not sync between devices.
- Clearing browser website data may erase entries, so keep a private backup of anything important.
- This personal prototype has no weight, calorie or body-measurement tracker.
- A public GitHub repository is visible to others. Do not put personal or sensitive information in its files.
